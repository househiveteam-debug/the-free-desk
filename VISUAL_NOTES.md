# Visual notes — screen-record The Free Desk at 1080p

Short checklist for a clean YouTube capture of this demo.

## Setup

1. Open the live demo in Chrome (or Edge) at **1920×1080**.
2. Use a calm desktop wallpaper; hide bookmarks bar and extensions.
3. Zoom browser to **100%**. Prefer light OS theme so the board stays high-contrast.
4. Click **Reset demo** once before recording so Inbox shows the six seed emails.

## Framing

- Record the full browser window (or a fixed 1920×1080 crop of the board).
- Keep the header, four rule chips, and all four columns (Inbox / Action / Waiting / Reference) visible.
- Avoid scrolling during the main triage pass if possible.

## Suggested 60–90s pass

1. Point at the rules strip (Under 2 min → Action, Waiting, Reference, otherwise Archive).
2. File one email → **Action**, one → **Waiting**, one → **Reference**.
3. **Archive** one newsletter-style item.
4. Show counts updating on each column.
5. Click **Reset demo** and pause on a full Inbox for an end card.

## Capture tips

- Mic: room tone low; say brand once — **The Free Desk** / **@TheFreeDesking**.
- Cursor: slow, deliberate clicks; no frantic mouse.
- Export: 1080p, 30fps, H.264; leave 0.5s hold on first and last frame.
- Thumbnail-friendly pause: board with mixed columns after triage.

## Brand

On-screen and in description: **The Free Desk** · **@TheFreeDesking** · no accounts · $0 stack.
